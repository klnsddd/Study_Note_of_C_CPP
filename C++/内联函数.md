- 是函数，通过”内存膨胀“的方式，以空间换时间
- 目的就是提高程序运行的速度，但有代价（内存）
- 节约的时间来自于调用函数，分配内存，释放内存
- 在函数本体和声明（若有）前加上 `inline` 关键字
- 写成内联函数的函数体不能太长，最好不要有循环
- 简单的赋值或者返回的语句，且**使用频率较高**，建议写为内联函数
	假设内联函数每次使用只能节省一点时间，但当它使用频率高时，就能节省很多时间

```C++

inline void func(int num);

int main()
{
	func(6);
	return 0;
}

inline void func(int num)
{
	printf("%d",num);
}
```
