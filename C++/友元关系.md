类的特性之一是封装，友元是打破封装的手段
友元分为友元函数和友元类
友元类可以创建友元对象
- 友元是单向的，谁是该类的朋友，朋友可以访问该类的全部内容，但该类不能访问朋友（朋友还没有把该类当作朋友）
- 友元是不传递（类的朋友的朋友不能访问该类）不继承的（朋友不能访问父类的子类）

```C++
#include <iostream>
using namespace std;

class A
{
	int num;
	friend void test1(A obj); //友元函数
	friend class B; //友元类
public:
	A(){num = 0;}
};

void test1(A obj)
{
	obj.num = 0;
}

class B
{
public:
	void test2(A obj)
	{
		obj.num;
	}
};

int main()
{
	A a;
	test1(a);
	return 0;
}
```
