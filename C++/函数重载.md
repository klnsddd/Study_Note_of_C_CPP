在同一个项目中定义的函数名字可以重复
	函数名必须一致
	函数的参数列表不同（可以个数不同，对应位置上类型不同）
	返回值类型不受限制（可以相同可以不同）
- 根据参数列表不同来寻找相应的同名函数
- 二义性：传的参数与重载函数类型皆不相同，会报错

```C++
int func(int n)
{

}

float func()
{

}

double func(int n, float v)
{

}

int main()
{
	func(); //无参，找第二个
	func(5); //一个int参，找第一个
	func(3, 3.0f); //第一个int参，第二个float参，找第三个
	func((int)3.14, 3.15);
	return 0;
}
```
