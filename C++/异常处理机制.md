`try`     尝试异常代码
`throw` 抛出异常 
`catch`  接收异常并执行解决代码
```C++
try
{
	直接或间接有throw，触发异常
}
catch(接收异常)
{
	处理
}
```

- `throw`抛出的异常信息，支持多种类型：字符串，字符，int, double
- `catch`接收的方式：
	`catch (const char* str)`
	`catch (int num)`
	`catch (...)`

```C++
#include <iostream>
using namespace std;

double test(double a, double b)
{
	/*if (b == 0.0)
	{
		cout << "!!!" << endl;
		return 0.0;
	}*/
	if (b == 0.0)
	{
		//有异常情况→打报告
		//throw抛出的异常信息，支持多种类型：字符串，字符，int double
		throw "!!!";
		//若抛出异常，后面的语句不会执行
	}
	return a / b;
}


int main()
{
	try
	{
		cout << test(9,0) << endl;
	}
	catch (const char* str)
	{
		cout << str << endl;
	}
	//或者
	catch (int num)
	{
		cout << str << endl;
	}
	catch (...)
	{
		cout << str << endl;
	}
	
	return 0;
}
```


# C++中的自定义异常

C++中一些存在的类可以存在标准异常

![[Pasted image 20251217190832.png]]
![[Pasted image 20251217190946.png]]

```C++
#include <iostream>
using namespace std;
#include <exception>

class Myexception : public exception
{
public:
	const char* what() const
	{
		return "自定义的异常"；
	}
};

int main()
{
	try
	{
		throw MyException();
		
	}
	catch(MyException& obj)
	{
		cout << obj.what() << endl;
	}
	
	return 0;
}
```
