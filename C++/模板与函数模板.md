# 模板与泛型编程
- 泛型编程：编写一些和类别无关的逻辑代码
	- 如相加：int类型能相加，float类型也能相加
	- 但对C++来说，面向对象很重要，所以可以向泛型编程中传类型
- 模板：实现代码重用的工具或方法
	- 可以实现类型参数化（也就是向泛型编程中传类型）
	- 模板分类：**函数模板**，**类模板**

# 函数模板

通过 函数模板 定义 模板函数
	`template <typename Type_1, ..., typename Type_n>`
	`type_n 返回值类型 函数名(形参列表) {函数体;}`
调用时：
	`函数名<类型列表>(实参列表);`
	类型列表可以缺省，编译器会自动判断类型
与普通函数的重载
	1. 函数模板可以重载，也可以与普通函数互相重载
	2. 当函数模板与普通函数构成重载时，优先调用普通函数，除非参数数量或类型与普通函数有差别，或直接指定了参数类型
模板函数的局限
	有时需要对类显式特化对应的模板，如判断类是否相等
	语法：`template<> 函数名<类名>(...)`

**函数模板的定义**
```C++
#include <iostream>
using namespace std;

template <typename Type>  //数据的类型列表
Type add(Type a, Type b)
{
	return a + b;
}

template <class TT1, class TT2>
void test(TT1 tt1, TT2 tt2)
{
	cout << "tt1 = " << tt1 << endl
		 << "tt2 = " << tt2 << endl;
}

int main()
{
	test(1, 2);
	test(1.23, 2.23);
	test("name", 's');
	
	cout << add(3, 4) << endl;
	cout << add(1.23, 2.46) << endl;
	// cout << add(6, 2.46) << endl;  //参数列表只有一种类型，会报错 
	cout << add<int>(6, 2.46) << endl; //可以传类型参数，前面的相当于参数缺省
	
	test<cosnt char*, char>("name", 's');
	
	return 0;
}
```

**函数模板重载与显式特化**
```C++
#include <iostream>
using namespace std;

#重载1
template <typename T>
void func(T a) {
    std::cout << "func(T)\n";
}

template <typename T>
void func(T a, T b) {
    std::cout << "func(T, T)\n";
}

#重载2（重载1和2没有关系，只看1或者2中的两个函数互为重载）
template <typename T>
void func(T a) {
    std::cout << "template\n";
}

void func(int a) {
    std::cout << "normal\n";
}

#显式特化
class MyData
{
public:
	MyData(int n = 0): num(n){}
	
	int num;
};

template <typename T>
bool func(T& a, T& b)
{
	if (a == b)
		return true;
	return false;
}

template<> 
bool func<MyData>(MyData& a, MyData& b)  //对Mydata类进行函数模板的重载
{
	if (a.num == b.num)
		return true;
	return false;
}


int main()
{
	int num = 9;
	int val = 9;
	
	cout << (func(num, val) ? "true" : "false") << endl;
	
	MyData obj_1, obj_2;
	cout << (func(obj_1, obj_2) ? "true" : "false") << endl;
	
	return 0;
}
```
