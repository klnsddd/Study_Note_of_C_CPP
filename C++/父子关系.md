# 派生类的构成
1. 基类的全部成员（除了拷贝、构造、析构函数）
2. 自己新创建的成员
3. 派生类创建的与基类同名的成员，会隐藏继承来的基类的该成员（但仍占有内存），可通过 `基类名::成员名` 访问继承来的成员，否则默是派生类的该重名成员
4. 多个基类中若有重名成员，必须通过 `基类名::成员名` 访问

```C++
#include <iostream>
using namespace std;

class Father
{
public:
	Father();
	~Father();
	int val;
	int num;
};

class Father_1
{
public:
	Father_1();
	~Father_1();
	int val;
};

class Son : public Father, public Father_1
{
public:
	Son();
	~SOn();
	int num;
};

int main()
{
	Son obj_son;  //表面上只有两个成员，但隐藏了父类的num，实际有三个
	obj_son.num;
	cout << "obj_son.num = " << obj_son.num << endl;
	cout << "obj_son.Father::num = " << obj_son.Father::num << endl;
	cout << "obj_son.Father::val = " << obj_son.Father::val << endl;
	cout << "obj_son.Father_1::val = " << obj_son.Father_1::val << endl;
	return 0;
}

Father::Father()
{
	val = 10;
	num = 20;
}
Father::~Father()
{
}

Father_1::Father_1()
{
	val = 20;
}
Father_1::~Father_1()
{
}

Son::Son()
{
	num = 99;
}
Son::~Son()
{
}
```


# 子类与父类的关系
子类是父类的对象，但父类对象不是子类的对象。或者说，子类对象可以当作父类对象来使用，但父类对象不能当作子类对象来使用
- 举例1：子类内存大于等于父类，父类无法给子类赋值完全，但子类可以给父类赋值完全，舍弃多余的部分即可
- 举例2：子类指针跨度大于父类，子类对象指向父类对象时，会读出不属于父类对象的内存，因此禁止；但父类对象的指针可以指向子类对象，尽管有部分子类对象的内存访问不到，但没关系

```C++
#include <iostream>
using namespace std;

class Father
{
public:
};

class Son : public Father
{
public:
};

int main()
{
	Father obj_fat;
	Son obj_son;
	
	obj_fat = obj_son;
	// obj_son = obj_fat;
	
	Son* p_son;
	Father* p_fat;
	
	p_fat = &obj_son;
	// p_son = &obj_fat;
	return 0;
}
```

# 派生类的构造析构顺序
先构造父类，再构造子类
先析构子类，再析构父类（入栈出栈）
	子类的构造析构，会自动触发父类的构造析构
如何构造子类时传参给父类构造函数：初始化成员列表中写入父类构造函数

```C++
#include <iostream>
using namespace std;

class Father
{
public:
	Father();
	Father(int n);
	~Father();
	const int num;   //如何在创建子类时初始化父类中的const变量
};

class Son : public Father
{
public:
	Son();
	Son(int n, int v);
	~Son();
	int val;
};

int main()
{
	Son obj_son(3, 4); 
	cout << "obj_son.num = " << obj_son.num << endl
		 << "obj_son.val = " << obj_son.val
		 << endl;
	return 0;
}
Father::Father() : num(0)
{
	cout << "父类构造" << endl;
}
Father::Father(int n) : num(n)
{
	cout << "父类带参构造" << endl; 
}
Father::~Father()
{
	cout << "父类析构" << endl;
}
Son::Son()
{
	val = 10;
	cout << "子类构造" << endl;
}
Son::Son(int n, int v) : Father(n) //利用初始化列表，将父类的const变量初始化
{
	val = v;
	cout << "子类带参构造" << endl;
}
Son::~Son()
{
	cout << "子类析构" << endl;
}
```
