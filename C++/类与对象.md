# 类与对象

类是一种用户自定义的数据类型（函数，数据）
类是具有相同的属性和行为的对象的集合
类是对象的抽象，对象是类的具体
对象：通过类类型定义的变量

## 定义类

public 都可以访问
private 只有该类内可以访问
protected 该类和该类的继承类都可以访问
```C++
class classname;
{
// 默认是私有的
	//成员：1 数据 2 函数

//访问权限修饰关键字
public:          //公有的
	//成员：1 数据 2 函数
private:         //私有的
	//成员：1 数据 2 函数
protected:       //被保护的
	//成员：1 数据 2 函数
};
```

## 定义对象

- 对象的成员通过 `.` 来访问
- 私有的数据不好从外部访问，可以通过公有的函数去访问
- 类的指针不再通过 `.` 来访问，通过 `->` 访问

```C++
#include <iostream>
using namespace std;

class Sheep
{
public:
	char name[32];
private:
	int age;
	
public:
	void setAge(int n)
	{
		age = n;
	}
	void eat()
	{
		cout << "eat" << endl;
	}
	void speak();
private:
	void speakEng()
	{
		cout << "My name is " << name << ", i am " << age << "years old. " << endl;
	}
};

void Sheep::speak()
	{
		cout << "我的名字是" << name << ", 我" << age << "岁了。" << endl;
	}

int main()
{
	Sheep xyy;
	xyy.eat();
	strcpy(xyy.name, "xyy");
	//xyy.age = 10; //private不能从外部访问
	xyy.setAge(12);
	xyy.speak();
	
	Sheep* py = &xyy;
	py->eat();
	py->speak();
	return 0;
}
```

## class 与 struct

- C++中，`class` 与 `struct` 关键字都可以用来定义类
- C中既不能用 `class`，且`struct` 内也不能定义函数
- C++中， `struct` 既可以定义类，也可以定义结构体
- 尽量不要用 `struct` 去定义类，以防混淆
