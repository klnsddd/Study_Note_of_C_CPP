- 类模板可以定义对象，这些对象有着同名的成员，但同名的成员可以有不同的类型
- 未传入参数类型的类模板不能直接定义对象

```C++
template <类型参数列表>
class 模板类名
{
	成员;
};

类型参数列表: <class T1, ..., class Tn>
```

```C++
#include <iostream>
using namespace std;

template <class Type1 = int, class Type2 = double>
class MyData
{
public:
	MyData(Type1 n = 0, Type2 v = 0.0) : num(n), val(v){};
	Type1 getNum() {return num;}
	Type2 getVal() {return val;}
	void setNum(Type1 n) { num = n;}
	void setVal(Type2 v) { val = v;}
	
	void showData();
	
private:
	Type1 num;
	Type2 val;
}

//类模板中的函数写在外面的方法
template <typename T1, typename T2>
void MyData<T1, T2>::showData()
{
	cout << "num = " << num << "val = " << val << endl;
}


int main()
{
	//利用类模板定义对象的方法，类型的传入可以缺省（类模板定义中要有默认类型才可以缺省）
	MyData<> data_0(3, 3.14); //有默认类型时，<>不能省略
	MyData<int, double> data_1(3, 3.14);//无默认类型时
	data_1.showData();
	MyData<char> data_2(67, 3.14);
	data_2.showData();
	MyData<char, float> data_3(68, 3.14);
	data_3.showData();
	
	return 0;
}
```

# 类模板做函数的参数

1. 方法一，直接限定传入的参数，局限性强
2. 方法二，利用函数模板，类型可以自由使用
3. 方法三，直接传类，连参数都不用传了

```C++
#include <iostream>
using namespace std;

template <class Type1 = int, class Type2 = double>
class MyData
{
public:
	MyData(Type1 n = 0, Type2 v = 0.0) : num(n), val(v){};
	Type1 getNum() {return num;}
	Type2 getVal() {return val;}
	void setNum(Type1 n) { num = n;}
	void setVal(Type2 v) { val = v;}
	
	void showData();
	
private:
	Type1 num;
	Type2 val;
}

template <typename T1, typename T2>
void MyData<T1, T2>::showData()
{
	cout << "num = " << num << "val = " << val << endl;
}

//方法一，直接限定传入的参数，局限性强
void test_Func_1(MyData<int, double>& obj)
{
	obj.showData();
}

//方法二，利用函数模板，类型可以自由使用
template <typename TT1, typename TT2>
void test_Func_2(MyData<TT1, TT2>& obj)
{
	obj.showData();
}

//方法三，直接传类，连参数都不用传了
template <class T>
void test_Func_3(T& obj)
{
	obj.showData();
}


int main()
{		
	MyData<int, double> data_1(3, 3.14);
	test_Func_1(data_1);
	test_Func_2(data_1)
	
	MyData<char> data_2(67, 3.14);
	test_Func_2(data_2);
	
	MyData<char, float> data_3(68, 3.14);
	test_Func_3(data_3);
	test_Func_3<MyData<char, float>>(data_3);
	
	return 0;
}
```

# 类模板和继承

- 从父类继承前需要先确定成员类型，继承时传入类型参数列表即可

```C++
#include <iostream>
using namespace std;

template <class F_Type>
class Father
{
public:
	F_Type m_F_val;
};

class Son : public Father<int>
{
public:
	int m_S_Val;
};

template <class S_Type1, class S_Type2>
class Son_1 : public Father<S_Type1>
{
public:
	S_Type2 m_S_Val;
};


int main()
{
	Son_1<int, double> obj_son;  //int传给Father，double传给Son_1
	obj_son.m_F_val;
	obj_son.m_S_val;
	
	return 0;
}
```

# 类模板和友元

- 类模板最好不要用友元函数，比较麻烦
- 如果必须用友元函数，最好在类中定义友元函数体
- 若必须是类中声明，类外定义，则
	1. 声明中多写一个`<>`
	2. 提前声明类模板和友元函数

```C++
#include <iostream>
using namespace std;

//若要在类外定义友元函数体,则需要提前声明类模板和友元函数
template <class T>
class A;
template <typename T>
void show_2(A<T>& obj);
 
template <class T = int>
class A
{
public:
	A(T t=0) : m_a(t){}
	
	friend void show_1(A<T>& obj)
	{
		cout << obj.m_a << endl;
	}
	
	//声明的方法,需要加<>,这样调用该函数时会把类模板的T类传给函数模板的T
	friend void show_2<>(A<T>& obj);
	
private:
	T m_a;
}

//利用函数模板实现类外的友元函数定义
template <typenameT>
void show_2(A<T>& obj) //去掉多余的<>
{
	cout << obj.m_a << endl;
}


int main()
{
	A<int> obj_a(666);
	show_1(obj_1);
	
	return 0;
}

```

# 注意事项

- 模板类的声明和类中成员函数的实现需要写到一个文件中，不能用引用头文件的方式来写到两个文件中。该文件可以命名为`hpp`为后缀。
