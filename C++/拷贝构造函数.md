拷贝构造是一种特殊的构造函数
通过拷贝构造函数完成一个复制的过程（复制一个对象）
特殊：**第一个参数是本类的对象的引用**

先是构造函数，才可能是拷贝构造函数
有低保：没写系统给默认的，将成员一一对应赋值
可以自定义

先构造的后析构，因为直接创建的对象存储在栈区，出入栈 

调用时机：
	使用一个对象给另一个对象进行初始化
		`Monster m2 = m0;`
	使用一个对象构造另一个对象
		`Monster m3(m0);`
	函数的参数是类的对象（实参被拷贝给了形参）
		`void test_func_1(Monster obj){}`
	函数的返回值是类的对象（形参被拷贝给了实参）
		`Monster test_func_2() {Monster obj; return obj;}`

浅拷贝与深拷贝
	浅拷贝：默认都是浅拷贝，无脑抄袭
	深拷贝：需要自己根据实际情况实现，如指针不能随便抄
	怎么防止默认拷贝发生：
		声明一个私有的拷贝构造函数，但不对它定义，当拷贝发生时一定会报错，此时就知道有拷贝发生了，然后再判断是否需要编写深拷贝
		主动让程序报错

当函数返回值或参数列表有对象时，如何防止触发拷贝构造（当对象是图像等占用内存很大的东西时，触发拷贝构造会使代码效率低下）
```C++
void func(const MyClass& obj);   // ✅ 只读，高效，无拷贝（最常用）
void func(MyClass& obj);         // ✅ 可修改，无拷贝
MyClass func()                   //返回“新对象”
MyClass& func()                  //返回“已有对象本身”
const MyClass& func()            //返回“只读对象”
```
