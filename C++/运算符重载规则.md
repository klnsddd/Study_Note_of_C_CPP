- 不是所有的运算符都可以重载
- 重载不能改变运算符的优先级和结合性
- 重载不会改变运算符的用法 
- 运算符重载函数不能有默认的参数
- 运算符重载函数可以作为类的成员函数，可以作为全局函数
- 箭头运算符`->`  下标运算符`[]`  赋值运算符`=`  函数调用运算符`()` 
	只能以成员函数的形式重载

**注意事项**
- 运算符重载的语法很简单，关键是规则
- 可以显式调用（写出函数），也可以隐式调用（直接写运算符）
- 注意与友元的联合使用，可以用const防止破坏类的封装性



# 输入<< 与 输出>> 重载

 - 建议作为友元函数重载
 - istream: 输入
 - ostream: 输出

```C++
#include <iostream>
using namespace std;

class MyComplex
{
public:
	MyComplex(double real = 0.0, double imag = 0.0)
		: m_real(real), m_imag(imag) {}
	friend istream& operator>>(istream& in, MyComplex& com);
	friend ostream& operator>>(ostream& out, MyComplex& com);
private:
	double m_real;
	double m_imag;
};

istream& operator>>(istream& in, MyComplex& com)
//若写成成员函数，this指针在前，与该参数顺序相反，修改很有难度
{
	in >> com.m_real >> com.m_imag;
	return in;
}
ostream& operator>>(ostream& out, MyComplex& com)
{
	out << "(" << com.m_real << "+" << com.m_imag << "i)";
	return out;
}

int main()
{
	MyComplex obj;
	cin >> obj;
	cout << obj << endl;   //如果不做输入输出重载，运算符还不认识obj
	
	operator>>(cin, obj);  //也可以这么写
	operator<<(cout, obj);
	
	MyComplex obj_1;
	
	cin >> obj >> obj_1;            //和下面这句代码等价
	operator>>(operator>>(cin, obj), obj_1);
	
	return 0;
}
```
