对一个变量或者对象取的别名
定义引用的时候必须要初始化（说明别名是哪个变量的）
- 用处：缩写变量名
引用和被引用用的是同一段内存

```C++
int main()
{
	int num = 0;
	int& dd = num;
	printf("num = %d\n", num);
	dd = 10;
	printf("num = %d\n", num);
	
	int gameControlNum = 9;
	int& gcn = gameControlNum;
	
	return 0;
}
```

# 在函数中使用引用

可以对返回值或者参数使用引用，直接使用函数外部的变量，不需要复制等操作，简单快捷
```C++
void func1(MyClass& obj);
MyClass& func2(); 
```
