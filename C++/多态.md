**多态（PLM, Polymorphism）**：  
	指的是 **“同一个接口（Interface），在不同对象上表现出不同的行为”**  
	通俗说就是：
	**同一句话（同一个函数调用），不同对象给出不同反应**
核心作用
	**用“基类指针/引用”统一操作“不同子类对象”**，而行为由子类决定
三个必要条件
	1. 虚函数成员的父类
	2. 同名函数成员的子类
	3. 指针：父类类型的指针，指向父类或者子类对象
虚函数
	函数声明前加 `virtual` 关键字
	特点
		1. 父类生成一个虚函数表，记录所有的虚函数（首地址）
		2. 生成一个四字节虚指针，指向虚函数表
		3. 继承的子类可以重写父类带有 `virtual`关键字的同名函数
		4. `virtual` 具有继承性，子类对父类虚函数的重定义，该函数仍然是虚函数
		5. 子类不会继承父类的虚函数表
		6. 在满足多态的必要条件情况下，对 `virtual`函数，会根据指针指向对象的类来调用对象类中的同名函数；若并非 `virtual`函数，则会根据指针的类去调用对应类的函数。下面的示例中，若没有 `virtual`, 则只会输出Father
		7. 当父类中有任意虚函数且使用父类指针分配子类对象时，父类的析构函数也要写成虚函数，否则无法正常调用子类的析构函数（因为子类的析构也要从指针来调用），从而导致内存泄露

```C++
#include <iostream>
using namespace std;

class Father
{
public:
	Father();
	virtual ~Father();  //父类虚析构函数
	
	virtual void test_func();  //声明一个虚函数
};

class Son_1: public Father
{
public:
	Son_1();
	~Son_1();
	
	void test_func();
};

class Son_2: public Father
{
public:
	Son_2();
	~Son_2();
	
	void test_func();
};

int main()
{
	Father* p_fat;  //父类指针
	
	Father obj_fat;
	Son_1 obj_Son1;	
	Son_2 obj_Son2;
	
	p_fat = &obj_fat;
	p_fat->test_func();
	
	p_fat = &obj_Son1;
	p_fat->test_func();
	
	p_fat = &obj_Son2;
	p_fat->test_func();
	//用“基类指针/引用”统一操作“不同子类对象”，而行为由子类决定，这里分别是Father, Son_1, Son_2不同的三种输出结果
	
	Father* p_father = new Son_1;
	p_father->test_func();
	delete p_father;
	p_father = NULL;
	
	return 0;
}

Father::Father()
{
	cout << "Father::Father()" << endl;
}

void Father::test_func()
{
	cout << "Father::test_func()" << endl;
}

Father::~Father()
{
	cout << "Father::~Father()" << endl;
}

Son_1::Son_1()
{
	cout << "Son_1::Son_1()" << endl;
}

void Son_1::test_func()
{
	cout << "Son_1::test_func()" << endl;
}

Son_1::~Son_1()
{
	cout << "Son_1::~Son_1()" << endl;
}

Son_2::Son_2()
{
}

void Son_2::test_func()
{
	cout << "Son_2::test_func()" << endl;
}

Son_2::~Son_2()
{
}
```

# 实际应用价值

多态真正厉害的地方：你“加新按钮”，旧代码（`handleClick`）一行都不用动
```C++
class Button {
public:
    virtual void onClick() = 0;   // 纯虚函数（Pure Virtual Function）
    virtual ~Button() {}          // 多态基类析构必须 virtual
};

class LoginButton : public Button {
public:
    void onClick() override {
        std::cout << "Login\n";
    }
};

class CancelButton : public Button {
public:
    void onClick() override {
        std::cout << "Cancel\n";
    }
};

void handleClick(Button* btn) {   // ✅ 统一传参
    btn->onClick();               // ✅ 多态调用
}

int main() {
    Button* b1 = new LoginButton();
    Button* b2 = new CancelButton();

    handleClick(b1);   // 输出 Login
    handleClick(b2);   // 输出 Cancel
} //多态真正厉害的地方：你“加新按钮”，旧代码一行都不用动
```
