是一种特殊的成员函数，主要用来在创建对象时初始化对象
——为对象的成员变量赋初始值
- 构造函数名和类名相同
- 构造函数没有返回值类型，也没有返回值
- 构造函数可以重载，需要满足函数重载的条件
- 若类内没有定义构造函数，系统会默认给一个空的构造函数，且该默认函数是内联函数
- 但若自己定义了构造函数，就不会有默认的空构造函数了，创建对象时要对应自己编写的构造函数的参数列表
- 构造函数会在创建对象时自动调用，且不能通过`对象名.构造函数名`来额外调用
- 构造函数需要写在 `public` 下
- 有时数据成员（比如`const`修饰的）必须初始化，却又不能在构造函数中赋值 
	用**成员初始化列表**的方式给数据成员赋值
	只能写在定义函数后面，不能写在声明后面

```C++
#include <iostream>
using namespace std;

class MyClass
{
public:
	int num;
	const int id ;
private:
	int val;

public:
	MyClass()
	{
		cout << "MyClass()" << endl;
	}
	
	MyClass(int n, int v = 2)
	{
		num = n;
		val = v;
		cout << "MyClass(int n, int v)" << endl;
	}
}

int main()
{
	MyClass obj_0;
	MyClass obj_1(1);
	MyClass obj_2(1, 2);
	
	MyClass* p_0 = new MyClass;
	MyClass* p_1 = new MyClass(6, 7);
	
	return 0;
}
```

### 成员初始化列表
```C++
#include <iostream>
using namespace std;

class MyClass
{
public:
	const int id ;
	const int num ;

public:
	MyClass(int i, int n) :id(i), num(n)
	{
		
	}
}

int main()
{
	MyClass obj_2(1, 2);
	
	return 0;
}
```
