# 一、什么是“联编”（Binding）

**联编（Binding）**：  
👉 指的是 **“函数调用 与 具体函数实现 之间的绑定关系”**  
也就是：**到底调用哪一个函数，是在什么时候确定的？**

# 二、联编的两种类型

C++ 中主要有两种：

| 类型     | 英文              | 确定时间              | 是否支持多态 |
| ------ | --------------- | ----------------- | ------ |
| ✅ 静态联编 | Static Binding  | 编译期（Compile-time） | ❌ 不支持  |
| ✅ 动态联编 | Dynamic Binding | 运行期（Run-time）     | ✅ 支持   |

# 三、静态联编（Static Binding）

### 定义

在 **编译阶段就确定** 调用哪个函数。
### 特点

- 编译时就“绑死”
- 执行快
- **不支持多态（Polymorphism）**
### 常见情况

- 普通函数
- 非 `virtual` 的成员函数
- 函数重载（Overload）

### ✅ 示例

```cpp
class A {
public:
    void show() {
        std::cout << "A::show\n";
    }
};

int main() {
    A a;
    a.show();   // ✅ 编译期确定，静态联编
}
```

# 四、动态联编（Dynamic Binding）

### 定义

在 **程序运行时才确定** 调用哪个函数。
### 特点

- 依赖 **虚函数（Virtual Function）**
- 依赖 **基类指针 / 引用**
- 是 **C++ 多态（Polymorphism） 的基础**

### 三个必要条件（缺一不可）

**基类函数用 `virtual` 修饰**  
**通过基类指针 或 引用 调用函数**  
**派生类重写（override）该函数**

### ✅ 示例（标准多态例子）

```cpp
class Base {
public:
    virtual void show() {   // ① virtual
        std::cout << "Base::show\n";
    }
};

class Derived : public Base {
public:
    void show() override { // ② 重写
        std::cout << "Derived::show\n";
    }
};

int main() {
    Base* p = new Derived();  // ③ 基类指针指向子类
    p->show();               // ✅ 运行期决定 → 调用 Derived::show
}
```

✅ 输出：

```
Derived::show
```

这就是 **动态联编 + 多态**。

# ✅ 五、联编 & 多态 的一句话关系

**多态（Polymorphism）是基于“动态联编（Dynamic Binding）”实现的**

没有 `virtual` → 只能是静态联编 → 没有多态。

# 六、面试 / 考试标准总结模板（你可以直接用）

C++ 中的联编是指函数调用与函数实现之间的绑定方式，分为静态联编和动态联编。静态联编在编译阶段完成，效率高，但不支持多态，如普通函数调用和非虚函数调用；动态联编在运行阶段完成，依赖虚函数、基类指针或引用以及函数重写，是实现多态的基础。
