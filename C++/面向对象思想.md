# 面向过程

提出问题--分析问题--处理问题
大问题 → 小问题
做好这一步，做下一步，直到做完所有

优点：
	1. 条理清晰，使问题简单化，解决一个个小问题而不用直接解决困难的大问题
	2. 程序结构简单，顺序选择循环三种
	3. 对整个问题有清晰的把控，小问题之间是否会相互影响

缺点：
	1. 数据和操作是分开的，比如说函数是操作，需要传参也就是数据传入，当数据类型发生变化时，代码或者说函数修改代价太大
	2. 数据是透明公开的，不具备封装性，例如加密
	3. 多人协作开发难，一处修改可能处处修改，标识符重名等问题 

# 面向对象

面向对象的程序设计是面向过程的继承和发展
面向对象可以理解为：现实世界是由对象组成的
对象在程序中抽象为两个部分：属性，行为 （或者说数据、函数）

例如：鼠标
	行为：点击右键，点击左键
	属性：bool类型是否点击左键，颜色，价格


当用面向对象思想解决问题时，需要先实现一个类，然后创建对象，通过对象解决问题

举例：要洗澡
创建人这个类（有身体的各个部位，会洗澡），实例化（具体化）一个人（对象）叫张三，操作这个人完成任务


面向对象特点：
- 数据和行为结合在一起
- 容易修改维护和拓展，代码重复使用率较高（重用）
- 三大特性：封装、继承、多态     （也可以加上：抽象成类）
- 多线程 低耦合（耦合——内聚）
- 组件编程、代码托管、适配器模式
