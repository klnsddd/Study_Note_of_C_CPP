-     A ===> B
	父类       子类
	基类      派生类
- 子类继承自父类，父类派生出子类
- 单继承，多继承（有多个父类）
- 继承权限
	1. 公有继承 public   （使用最多的继承）
	2. 私有继承 private
	3. 保护继承 protected
- 继承是子类继承父类的全部成员（除了拷贝、构造、析构函数）
- 继承的访问权限

| 访问权限              | public继承  | private继承 | protected继承 |
| ----------------- | --------- | --------- | ----------- |
| **父类public成员**    | public    | private   | protected   |
| **父类private成员**   | 不可访问      | 不可访问      | 不可访问        |
| **父类protected成员** | protected | private   | protected   |
注意：子类继承得到的protected可以从类内访问到，但不能从类外访问

语法：
```C++
class 父类名1
{

};
class 父类名2
{

};

// 单继承
class 子类名 : 继承权限 父类名
{

};
// 多继承
class 子类名 : 继承权限 父类名1, 继承权限 父类名2
{

};
```

实例：
```C++
#include <iostream>
using namespace std;
class Father
{
public:
	Father();
	~Father();
	
public:
	int pub;
	void pub_func(){}
private:
	int pri;
	void pri_func(){}
protected:
	int pro;
	void pro_func(){}
	
};

class Son : public Father;
{
public:
	Son();
	~Son();
public:
	int num;
	void test_func()
	{
		this->pub;
		this->pub_func;
		//类内可以访问到父类的protected
		this->pro;
		this->pro_func;
		// this->pri;
		// this->pri_func();
	}
private:
protected:
};

int main()
{
	cout << "sizeof(Father): " << sizeof(Father) << endl;
	cout << "sizeof(Son): " << sizeof(Son) << endl;
	
	Son obj_son;
	obj_son.pub;
	obj_son.pub_func;
	// 以下报错，类外protected和private都不能访问
	/*
	obj_son.pri;
	obj_son.pri _func;
	obj_son.pro;
	obj_son.pro _func;
	*/
	
	return 0;
}

Father::Father()
{
}

Father::~Father()
{
}

Son::Son()
{
}
Son::~Son()
{
}
```
