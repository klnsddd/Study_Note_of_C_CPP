- 没有函数体的虚函数
- 若在一个类族中，某虚函数只有在各子类中才有意义，而父类不会调用该虚函数，则可以在父类中直接写成纯虚函数，只通过子类重定义并在子类中使用该函数。
- 重定义后的纯虚函数在子类中变为虚函数
- 抽象类
	- 类在拥有一个或一个以上的纯虚函数时，就变为了抽象类
	- 抽象类不能被用来实例化对象，但可以定义指针来指向子类对象
	- 若子类未将抽象父类的所有纯虚函数都重定义，那么该子类仍是抽象类（注意析构函数不会被继承，所以虚析构函数不算在内）

```C++
#include <iostream>
using namespace std;

class Father
{
public:
	Father();
	~Father();
	virtual void test_func() = 0;  //并非赋值，只是语法格式
};
class Son : public Father
{
public:
	Son();
	~Son();
	void test_func();
};

int main()
{
	
	return 0;
}

void Son::test_func()
{
	cout << "Son::test_func()" << endl;
}
```
