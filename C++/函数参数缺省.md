形参只在定义函数的时候写一次，而函数可以多次调用传入实参，所以实参的使用次数会更多，因此缺省是缺省实参，可以降低代码工作量，保证漏写参数时函数还能运行

参数缺省
	声明函数某个参数的时候指定一个默认值
	调用该函数时如果采用默认值，无需指定该参数
	1. 参数的传递是依次从前往后，因此**缺省时必须从后往前**
	2. 默认值必须是常量，不能是变量
	3. 若函数有声明，则只需要在声明时给出默认值，函数定义的时候不要在给默认值了

```C++
void function(int num, float val = 0.0f)
{
	printf("num = %d, val = %f\n", num, val);
}

int main()
{
	function(6, 3.14f);
	function(8);
	return 0;
}
```

### 与函数重载冲突

注意写函数要容易区分，使用函数时同时符合两个重载函数的情况会报错

```C++
void function(int num = 0, float val = 0.0f)
{
	printf("num = %d, val = %f\n", num, val);
}

void function()
{
	printf("void");
}

int main()
{
	function(6, 3.14f);
	function(8);
	function(); //冲突报错
	return 0;
}
```
