命名空间是用来组织和重用代码的编译单元
通过命名空间来避免冲突，解决重名现象
作用域运算符 ::

使用方法： `命名空间名字::变量名`

- 可以嵌套：命名空间里定义命名空间
- 同名的命名空间称为命名污染，但他们是同一个空间
- 命名空间也可以取别名
- `using namespace NAME_1` 在头文件后写using，整个文件中就会默认使用`NAME_1`中的变量
- `::` 没有前缀表示调用全局命名空间里的名字，明确调用 POSIX 系统函数

```C++
//using namespace NAME_1

namespace NAME_1
{
	int num = 10;
	float val = 11.1f;
	void func_1()
	{
		printf("func_1\n");
	}
	void func_2();
	namespace NAME_2
	{
	
	}
} //不用加分号

namespace N = NAME_1;

namespace NAME_1
{
	char name = "lisi";
}

void NAME_1::func_2()  //这样就和命名空间里的func_2联系上了
{
	printf("func_2\n");
}

int main()
{
	int num = 9;
	printf("num = %d\n", num);
	printf("num = %d\n", NAME_1::num);
}
```
