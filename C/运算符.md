## 算数运算符

\+  \-  \*  \/  \%(求余)  \++(自增)  \--(自减)

- /和%
	除分为整除和除
		整除：两个操作数都是整型，结果取商舍弃余数。
		除：两个操作数有一个时浮点数，相当于数学中的除
	余：只能是整数进行操作，结果取余舍弃商
- ++ 和  -- （单目运算符）
	前置：先运算再赋值
	后置：先赋值再运算
```C++
int age1 = 20;
int age2 = 20;
printf("front++: %d\n", ++age1);
// output: 21
printf("back++: %d\n", age2++);
// output: 20
```

## 位运算符
- 靠近底层计算机逻辑时用的比较多，比如算反码，补码
- 假设把两个short数据保存进一个int数据时，就会用到位运算。例如，鼠标位置是一个int，高位是x坐标，低位是y坐标
&：位与
|：位或
~：位非
^：位异或
	**两次位异或可以不通过中间变量实现变量交换（详见下方代码）**
		x⊕x=0; x⊕0=x; x⊕y⊕x=y;
<<：位左移
	左边移出去的溢出不要，右边空出位都补0
	位左移n位，相当于乘2的n次幂
	**所以实际操作中可以用左移代替乘2的n次幂，效率更高**
\>>：位右移
	右边移出去的溢出不要，左边空出位要看正负，正数补0，负数补1
	位右移n位，相当于整除2的n次幂

```C++
int a = 2;
int b = 3;
printf("%d\n", a & b);
// output: 2
printf("%d\n", a | b);
// output: 3
printf("%d\n", a ^ b);
// output: 1
printf("%d\n", a << 1)
// output: 4

a = a ^ b;
b = a ^ b;
a = a ^ b;
// 实际上：设a初始值为a1，b初始值为b1
// b = a1 ^ b1 ^ b1, a = a1 ^ b1 ^ a1 ^ b1 ^ b1


char c = 2;
printf("%d\n", ~c);
// output: -3
// (2)00000010 → (-3)11111101
// 负数二进制求法：整数的补码+1
// -3：3 → 00000011 → 11111100 → 11111101 → -3
```

## 赋值运算符

=, +=, -=, \*=, /=, %=, &=, \^= ...
带运算符的赋值运算符：进行运算后赋值

```C++
a += 3;
// a = a + 3
a ^= b;
// a = a ^ b
```

## 其他运算符

### sizeof
```C++
printf("%d\n", sizeof(int)); //括号里给类型
printf("%d\n", sizeof(a)); //括号里给变量
printf("%d\n", sizeof(3.14)); //括号里给常量
```

### 条件运算符    ?

唯一一个三目运算符
**操作数1，表示真假，如果为真，执行操作数2，如果为假，执行操作数3**

```C++
int a = 10;
int b = 20;
int max = (a > b) ? a : b;
printf("max = %d\n", max);
```

### 逗号运算符  ，

按从左至右的顺序依次执行各个操作数，最后的结果为最右侧的操作数

```C++
int x, y, z;
z = ((x=2), (y=4), (x+y));
// z = 2 + 4 = 6
```
