整型，浮点型，字符型

在计算机中不仅要关心数值，还要关心所占大小（内存）
电脑中最小的单位（位）bit
最小的存储单位（字节）byte
8GB = 8 \* 1024MB
1GB = 1 \* 1024KB
1KB = 1 \* 1024B(byte)
1Byte = 8Bit    1字节可以表述的数据有256

1字节 256个数
2字节 256 \* 256 = 65536

**整型**          1 10 100
	short   （短整型）    占2字节      -32767~32767
	int       （整型）       占4字节      约-21亿~21亿
	long    （长整型）    占4字节      约-21亿~21亿
- 特定环境下长度可能有变化，但short不大于int，long不小于int
- `sizeof(short)` 求括号内类型所占内存大小
- 了解取值范围可以更好的节约内存


**浮点型**          1.8  3.14
	float       （单精度）    占4字节
	double    （双精度）   占8字节
- 绝大部分情况下数据范围都能被float包含

**字符型**            ‘a’   ‘M’
	char          (字符型)       占1字节
- 用英文单引号括起来的字符
- ASCII码     a对应97
```C
for (int i = 0; i < 128; i++)
	printf("%d = %c\n", i, i);
	//%d输出一个整型 %c输出一个字符
return 0;
```

# 强制类型转换（Type Casting）

**强制转换不会改变变量本身的类型**，只是临时“以另一种方式解释”。

**方法：**
(类型名) 表达式

```C++
int a = 10;
float b = (float)a;
```
