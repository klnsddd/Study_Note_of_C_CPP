# 表达式
表达式是一种有值的语法结构，它由运算符将变量、常量结合而成

运算符应操作相同类型的变量或常量
变量或常量在通过运算符结合时，如果类型不一致，会发生类型转换
- 自动转换：小类型转大类型（如char转int）
- 强制转换：大类型转小类型（如double转int）
	（类型名）变量或常量：表示强制转换
- 对于基本数据类型，VS会自动帮助实现强制转换，但仍然建议手写

```C++
int hp = 10;
hp = hp + (int)2.0f;
```

# 语句

当程序运行时执行某个动作的语法结构

即一行行代码，用分号结尾

语句分类：
	空语句：；
	表达式语句：a += 2;
		注：x+y是语句，但是没有用
	函数调用语句
		例如，printf("%d\n", a);  %d格式化输出整数，%f输出浮点，%c 输出字符， 
            %s 输出字符串(遇到\\0会停止输出)
		scanf_s("%d\n", &a);       **scanf不安全，已被弃用**
			格式化输入，输入时会阻塞，等待用户输入
			1. 双引号中表示格式化输入的字符串，输入时要遵循这个字符串的格式
			2. 要输入的变量前面加&
			3. 输入多个数据时，有结束符，一般情况下用回车或者空格来表示结束，但如果格式化字符串中有其他字符，那么其他字符就可能是结束字符
				推荐：scanf_s("%d%d", &a, &b);
	复合语句：{ } 包含的多条语句，当成一条语句来执行
	控制语句：选择、分支、循环、跳转
