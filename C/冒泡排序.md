排序规则：
n个数字
冒泡n-1次
第k次需要比较n-k-1次(从0开始计次)

求升序

```C++
int main(void)
{
	int arr[5] = {4,1,2,5,3};
	int n=5;
	for (int i=0; i<n-1; ++i)
	{
		for (int j=0; j<n-1-i; ++j)
		{
			if(arr[j]>arr[j+1])
			{
				int tempVal = arr[j];
				arr[j] = arr[j+1];
				arr[j+1] = tempVal;
			}
		}
	}
	for (int i=0; i<n; i++)
		printf("%d\t", arr[i]);
	
	return 0;
}
```

# 封装冒泡排序函数并采用随机数

计算机的随机数是伪随机数，每次运行程序都会给出固定的随机数
	可以通过时间来设置种子数来获得更真实的随机数
		`srand((unsigned int)time(NULL));`
		需要头文件`#include <stdlib.h>`
