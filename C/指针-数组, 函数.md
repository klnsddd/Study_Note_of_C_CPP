# 指针与数组
- 数组名即数组首地址
- 可以把数组名赋值给到一个指针，即把数组首地址赋值给一个指针，指针可以指向指针相同类型类型的数据，通过指针的方式去访问数据
- 数组名怎么使用，可以直接替换成指针名
- 指针名\[下标] → \*(指针名+整数)
	`p[2] → p+2 //p指向的地址的后第二个地址`
- 指针偏移：
	可以在一定范围内加减整数来做到移动地址
	+整数相当于 +sizeof(类型)\*整数

```C++
int main(void)
{
	int arr[4] = {1,2,3,4,5,6,7,8};
	int* p = arr; // p指向一个int数组
	p[0] = 100;
	p = &arr[2]; //指针指向了数组中下标为2的元素的首地址
	*p = 666;
	p--;p--;
	
	for(int i=0; i<4; i++)
	{
			printf("%d\n", p[i]);   //这两种用法相同
			printf("%d\n", *(p+i)); //建议指针使用这种写法
	}
	return 0;
}
```

## 字符串数组
```C++
int main(void)
{
	char name[16] = "abcdefg";
	char* pstr = name;
	printf("%s\n", pstr);
	while(*pstr)
	{
		printf("%c\n", *(pstr++));
	}
	return 0; 
}
```


# 指针与函数

1. 指针作为函数的参数  →  址传递，在函数内部通过地址的间接操作可以操作外部的实参
2. 函数的返回值类型为指针类型

```C++
int myAdd(int* a, int* b)
{
	return *a + *b;
}

void mySwap(int* a, int* b)   // 核心用法
{
	int c = *a;
	*a = *b;
	*b = c;
}

int* fun(void)     // 返回值为指针类型
{
	return NULL;
}

int main(void)
{
	int a = 1, b = 2;
	printf("%d\n", myAdd(&a,&b));
	mySwap(&a,&b);
	printf("a=%d\tb=%d\n", a, b);
	return 0;
}
```
