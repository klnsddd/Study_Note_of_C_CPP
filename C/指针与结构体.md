1. 结构成员为**指针**
	X86 表示32位（4字节）
	X64 表示64位（8字节） 此电脑为64位操作系统
2. 指针指向结构变量
	指针可以通过 `->` 运算去访问结构成员
	`->` 由结构体指针访问成员时专用，注意其类型是指针，不要多加解引用

```C++
struct MyStu
{
	int id;
	char* pName;
};

int main(void)
{
	struct MyStu ms; //在栈区占用内存
	ms.id = 1001;
	// ms.pName = "zhangsan"; //有两个内存区块，pName是ms内，在栈区，而值zhangsan是字符串常量，位于全局数据区，无法修改，例如： ms.pName[0] = 'Z';  // ❌ 错误！只读内存
	ms.pName = (char*)malloc(sizeof(char)*32);//pName在栈区，malloc分配的内存在堆区
	strcpy_s(ms.pName, 32, "lisi");  //把lisi复制进堆区的那 32 个字节空间
	printf("%s\n",ms.pName);
	free(ms.pName);
	printf("%d\n",sizeof(char*));
	//输出8；常见的 64 位程序中，一个地址通常需要64 bit保存，说明该系统是x64，注意：指针的sizeof都相同，因为不管是什么类型指针，地址长度是一样的
	
	struct MyStu* pMs;
	pMs = &ms;
	pMs->id = 1002;
	return 0;
}
```
