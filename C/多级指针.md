二级指针：`类型** 变量名;`    //用的较多
三级指针：`类型*** 变量名;`

核心用法：封装返回指针的函数
	或者说，在函数内需要修改指针实参（即修改指针指向的地址时），需要二级指针，传入函数的则需要是指针本身的地址
对于**二级结构体指针**，**注意**
	`LL** plist;`
	通过加括号来访问结构体指针的成员`(*plist)->pHead;`

```C++
void myFun(int** q, int num) //若此处是int* q, 则下面*q不再是指针, 与后续操作不匹配，因此看到函数需要的参数为二级指针时，要传给它一个指针的地址
{
	*q = (int*)malloc(num);
	for(int i=0;i<5;i++)
    {
        *(*p+i) = i;
    }
}

int main(void)
{
	int a = 10;
	int* p = &a;
	*p = 123;
	int** pp = &p; //二级指针, p是a的地址, &p是指针p的地址
	**pp = 999; //*pp是指针p的地址, **pp是操作p指向的a
	printf("%d\n",a);
	
	int* p1 = NULL;
	myFun(&p1, sizeof(int)*5);
	//经过myFun后，p指向的地址从0变为了malloc分配的内存地址
	for(int i=0;i<5;i++)
    {
        printf("%d ", *(p1+i));
    }	
	return 0;
}
```
