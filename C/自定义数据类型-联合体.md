也叫共用体，类似结构体
	不同类型的数据，共用一段内存
- 联合类型定义
	`union 联合类型名 {成员列表};`
- 联合变量在初始化时，只能给第一个成员初始化
	1. 可以理解为成员不能同时存在(互斥存在)（内存不够），
		举例：游戏过关条件作为一个定义的联合体，成员是各个关卡的过关条件，这样可以只用固定的内存描述不同的过关，而不用为每个过关条件分配内存
	2. 还可以理解为该段内存有不同的解释方式
		举例：`int color`和 `char c[4]`组为联合体，需要访问color的某字节时，可以走 `c[i]`，而不用采用位操作方法
- typedef，嵌套都可以实现

```C++
#include <stdio.h>
union MyData
{
	int i;
	short s;
};

union Data {
    int color;     // 4 字节
    char c[4];     // 4 字节
};

int main(void)
{
	printf("%d\n",sizeof(union MyData));
	// 4字节
	union MyData md = {1};
	md.i = 10;
	md.s = 2;
	
	union Data data;
	data.color = 0x12345678;
	printf("%x %x %x %x\n", data.c[0], data.c[1], data.c[2], data.c[3]);
	// 78 56 34 12
	
	return 0;
}
```
