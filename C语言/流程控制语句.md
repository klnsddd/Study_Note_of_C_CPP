# 代码执行顺序

顺序执行：从上往下依次执行
流程控制：**选择、分支、循环和跳转**

# 选择 if
## if 语句 → 如果（受条件影响执行）

- 后面跟圆括号，圆括号中一般是关系表达式或者逻辑表达式，如果是算术表达式，非0即为真
- if后面可以跟简单的一条语句（不用加花括号），也可以跟复合语句（加花括号），花括号不属于if语句的一部分
- 建议，习惯加上花括号
## if else 语句 → 如果 否则（单分支执行）

- else不能脱离if单独出现

```C++
int NpcHp;
scanf_s("%d", &NpcHp);
if (NpcHP<0)
{
	printf("npc die\n");
}
else
{
	printf("npc attack\n");
}
```
## if else if 语句（多分支执行）

```C++
int val;
scanf_s("%d",&val);
if (val > 90)
	printf("A\n");
else if (val > 70)
	printf("B\n");
else
	printf("C\n");
```


# 分支 switch

- switch 后面跟圆括号，圆括号里面一般是算数表达式，有一个整数结果
- 通过整数结果去case语句中匹配相应的数值，决定执行哪个分支
- 如果和所有case都匹配不上，执行default
- 注意：case只是表示一个分支的入口，switch 后面花括号内所有的语句都是内容。会从分支入口一直执行到花括号结束
- 如果需要只执行某个分支就结束，则需要搭配break语句
**if else if 与 switch 的区别**
	if else if 适用于范围表示
	switch 适用于值表示
	如果既能通过范围来表示，又能通过值表示，优先**switch**

```C++
int val;
scanf_s("%d", &val);
switch (val / 10) //算法实现的范围变值
{
case 9:
	printf("A\n");
	break;
case 8: // 80分的也会输出B
case 7:
	printf("B\n");
	break;
default:
	printf("C\n");
	break;
}
```

# 循环 for   while   do while

- 循环的条件：循环的计数，计数是否满足条件
- 三种循环语句 
	for     后面跟圆括号，圆括号中三个表达式
		int i=0    表达式1 → 计数的变量
		i <= 0     表达式2 → 计数是否满足条件
		i++         表达式3 → 计数变量的改变
		- 表达式与表达式之间用分号隔开
		- 执行流程：表达式1 → 表达式2 → 循环体（花括号内）→ 表达式3 → 表达式2 ......
		- 三个表达式都可以缺省（不写），但隔开表达式的分号不能缺省
			- 表达式1和3缺省表示什么都不做
			- 表达式2缺省表示死循环（永远为真）
		
	while    后面跟圆括号，圆括号中一般为关系表达式或逻辑表达式，如果是算数表达式，非0即为真
		一般在while循环前准备好计数器，且在循环内部进行计数器的修改
	do while
		- while 后面跟圆括号，圆括号中一般为关系，逻辑表达式，也可以是算数，不能缺省，**圆括号后面要加分号**
		- for 和 while 是先判断是否满足条件再执行循环
		- do while 是先执行，再判断是否满足条件，因此在条件一致的情况下，可能会比for、while多执行一次
- 注意：do while 后面要跟分号，for 和while圆括号后面跟分号表示循环体为空语句


```C++
for (int i=0; i<=100; i++)
{
	num += i;
}
printf("%d", num);


int a=0;
while (a<10)
{
	printf("%d\n", a++);
}


int a=0;
do
{
	printf("%d\n", a++);
}
while (a<10);
```

# 跳转 break  continue  goto

- break语句
	- 跳出当前循环或switch语句，结束循环或者switch语句执行
	- 只能跳出一重switch或循环
- continue语句
	- 作用于循环中，结束当前本次循环，进行下一次循环
	- 下一次循环要注意，如果是for，是先到表达式3（++i），再判断下一次循环
- goto语句
	- 无条件转移
	- 多重循环的跳出很方便
	- 谨慎使用，C语言中不限制程序中使用标号的次数，goto又可以无条件跳转到标号处，所有容易造成混乱

```C++
for (int i=0; i<10; ++i)
{
	if (i == 5)
	{
		printf("found it\n");
		break;
	}
	printf("%d\n",i);
}

while (i<10)
{
	if (i % 2 == 0) //表示偶数
	{
		i++;
		continue;
	}
	printf("%d\n", i);
	i++;
}
--------------------------------------------------

```
