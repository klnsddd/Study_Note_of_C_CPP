变量	variable	var
常量	constant	const
# 常量
常量：不能被修改的数据，可以用来给变量进行赋值
	类型
		数值常量                             95 0 -2 3.14
			整数默认为int  浮点数默认为double，如果想表达float 1.23f
			(var1 = 1.23, var2 = 1.23f)前者类型为double，后者为float
		字符常量（单引号）            ‘a’  ‘1’
		字符串常量（双引号）        “zhangsan”
	转义字符，用\表示转义
		\n 表示换行，\t表示水平制表（相当于按下tab，四下空格）
		\\\ 表示 \

# 变量
变量：可以被修改的数据
变量在使用之前一定要定义
定义方法：数据类型，变量标识符
	float height;   //表示学生身高
	int age;
	short age;
## 有符号与无符号整型变量
- 注意区分有符号与无符号整型变量
	int val = -100;
	unsighed short num = 123;
- 内存中，最高位为1表示负数，最高位为0表示正数
- 负数在内存中的存储，是该负数的绝对值，变成二进制之后，按位求反再+1
	例如，unsighed short num = -1，num会被实际赋值成255

## 常变量
用const关键字修饰的变量
- 定义格式：
	`const 数据类型 变量名;`
	如 `const char sex;`
- 定义时必须初始化赋值
	`const char sex = 'm'`
- 常用于不会有变化的变量，比如一个人的性别


# 例子
```C
#include <stdio.h>

int main(void)
{
	float height = 1.8f;
	printf("%f",height);
	short age = 20;
	char sex = 'm';
	
	int val = 100;
	unsigned char num = -1;
	printf("%d\n", val);
	printf("%d\n", num);
	
	const char sex1 = 'm';
	return 0;
}
```
