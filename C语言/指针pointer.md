- 用来表示地址
- 指针变量
	`类型名* 指针变量名;` 
- 赋值
	除了空地址 (NULL) 之外，不用常量来进行赋值
- 指针相关运算符
	\*  解引用   通过地址去找里面的数据
	& 取地址   取出某个变量的地址
- 指针的类型名应该与指向内存中的数据类型一致
- 指针能执行有限的运算符操作，两指针相加没有意义

```C++
int main(void)
{
	int* p = NULL;  //初始化赋值为空，指针没有指向任何地址
	double * pd; //星号分开也是可以的
	int* d, * e; //连续定义连个指针
	
	int a = 10;
	p = &a; //指针常用的赋值方式
	printf("%d\n", a);
	*p = 123;
	printf("%d\n", a);
	printf("%d\n", *p);
	
	return 0;
}
```

\* 不同的表现
1. 乘运算，左右两边为操作数
2. 表示指针，星号左边为类型名，右边为标识符
3. 解引用，右边为操作数

\& 不同的表现
1. 位与操作，左右两边为操作数
2. 取地址，右边为操作数


# 指针的赋值

| 写法                                                                       | 内存位置  | 可写性   | 生命周期 | 推荐程度      |
| ------------------------------------------------------------------------ | ----- | ----- | ---- | --------- |
| `char* p = "hello";`                                                     | 全局常量区 | ❌ 不可写 | 程序结束 | 🚫 不推荐    |
| `char str[20] = "hello";`  `char* p = str;`                              | 栈区    | ✅ 可写  | 函数结束 | ✅ 推荐（局部用） |
| `char* p = malloc(20);`        <br>`strcpy(p, "hello");`      `free(p);` | 堆区    | ✅ 可写  | 手动释放 | ✅ 推荐（长期用） |
指针只是“地址的容器”，安全使用的关键是：
- 不要指向只读常量；
- 最好指向你能控制的内存（栈或堆）；
- 若用堆，一定记得 `free()`；
- 若用栈，不要在函数返回后继续使用。
