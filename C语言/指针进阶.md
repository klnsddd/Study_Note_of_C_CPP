# 指针常量与常量指针

- **指针常量**：指针表示的地址是一个常量，意味着指针永远指向一个地址
	固定指向的指针，必须初始化，指针不能被修改
	**指针常量是常量，只能初始化不能修改自己，但可以解引用修改指向的值**
- **常量指针**：指针用来指地址，该地址的值里面认为是一个常量
	指向被认为是常量的变量或常量的指针，不能通过指针修改指向的值
	**常量指针是指针，可以修改自己，但不能修改指向的值**
- 若函数的参数中用到了指针，分析在函数中能不能对指针所指的内存进行修改，如果不能，要用常量指针，防止误修改
- **常量指针常量：既不能修改自己，又不能修改指向的值**
```C++
#include<string.h>
char* myStrcpy(char* dsStr, char const* srcStr)
{
	...
}

int main(void)
{
	const int lv = 3;
	int a = 3, b = 4;
	int* const p = &b;  //常量需要做初始化，后续不能被修改
	// p = &a;  //❌, 不能修改该指针的值（地址）
	*p =123; 
	
	const int* p1; //常量指针，是一个指针，指向一个常量
	int const* p2; //也是常量指针
	p1 = &a; //p1所指的a的内存，通过p1是无法修改a所在内存里面的值
	// *p1 = 123; //通过p1找到的地址里面的值是常量，不能修改
	// strcpy(); //该库函数就用到了常量指针
	
	const int* const p3 = &a;
	//p3 = &b;
	//*p3 = 123;   //两个都不能被修改
	return 0;
}
```

# 指针数组和数组指针

## 指针数组
- 指针数组：是一个数组，数组里面所有的元素是指针
	数组该怎么用就怎么用，通过数组找到里面的元素为指针，指针该怎么用就怎么用
- 动态二维数组的实现
- 字符指针数组——字符串数组
```C++
#include <stdlib.h>
int main(void)
{
	int arr[4] = {0};
	char str[16] = {0};
	
	int a = 0;
	int* pArr[3] = {0};//指针数组，数组里面有3个int*指针元素
	pArr[0] = &a;
	pArr[1] = (int*)malloc(sizeof(int)*3);
	pArr[2] = arr;
	//该指针数组的行由常量3决定，但列数可以由多个变量决定而不同
	
	//动态二维数组(数组的行列可以由变量给出，是直接定义数组所无法实现的)
	int row = 3, col = 4;
	int** p = (int**)malloc(sizeof(int*)*row); //右边表示在堆区分配了row个int*的连续内存（堆内存动态的指针数组）
	for(int i=0;i<row;i++)
	{
		*(p+i) = (int*)malloc(sizeof(int)*col);
	}
	for(int i=0;i<row;i++)
	{
		for(int j=0;j<col;j++)
		{
			*(*(p+i)+j) = i*col+j+1;
		}
	}
	for(int i=0;i<row;i++)
	{
		for(int j=0;j<col;j++)
		{
			printf("%d\t",*(*(p+i)+j));
		}
		printf("\n");
	}
	
	const char* pName[3] = {"zhangsan","lisi","wangwu"}; //指针数组，字符串数组
	printf("%s\n",pName[0]);
	
	return 0;
}
```

## （多维）数组指针
数组指针：是一个指针，指向一个数组
	一般认为指向二维及以上的数组为数组指针
	定义格式：
		二维：`数据类型 (*指针变量名)[所指的数组的列大小];`
		三维：`数据类型 (*指针变量名)[所指的数组的第二维大小][所指的数组的第三维大小];`
	数组名怎么用，数组指针名就可以怎么用
	- 解引用
		- 数组指针（如 `int (*p)[3]`）解引用一次 `*p`，得到的是一个数组（`int[3]`）的首地址；  
		- 再解引用一次 `**p`，得到的是该数组中的具体元素值。
	- 快速定义数组指针——类型重定义
		与之前类型重定义的格式稍有区别

```C++
typedef int HP;
typedef int(*PARR)[3]; //定义一个数组指针的类型，通过类型给出的变量，为可以指向列为3的二维数组指针

int main(void)
{
	int arr[4] = {1,2,3,4};	
	int arr1[2][3] = {1,2,3,4,5,6};
	int* p = arr;
	p = &arr1[0][0]; //由于多维数组在内存中是顺序排列的，所以也可以这样指向多维数组，但会有warning
	printf("%d\n", *p);
	
	// int* pArr[4]; //指针数组
	int (*pArr1)[3] = NULL; //数组指针，可以指向所有列为3(有三列)的二维数组
	pArr1 = arr1; //二维数组的首地址赋值给到指向所有列为3的二维数组指针上
	pArr1[0][0] = 123;
	printf("0x%x\n",*(pArr1+0)); 
	//*(pArr1 + 0)的类型是int[3]（数组），在表达式中它会衰变为int*，即&arr1[0][0]
	printf("0x%x\n",*(pArr1+1));
	//上面两句代码是在观察地址相差int[3]，也就是12个字节
	for(int i=0;i<2;i++)
	{
		for(int j=0;j<3;j++)
		{
			printf("%d\t", pArr1[i][j]);
			//printf("%d\t", *(*(pArr1+i)+j));
		}
		printf("\n");
	}
	
	int arr2[4][3]; //另一个列为3的数组
	pArr1 = arr2; //也可以由pArr1指向
	
	int(*pArr2)[2][3];
	
	PARR pa; //数组指针变量
	pa = arr1;
	
	return 0;
}
```


# 指针函数与函数指针

- 指针函数：是一个函数，返回值是指针（指针-数组, 函数 处已讲）
- 函数指针：是一个指针，指向一个函数
	函数也是有地址的，函数名即函数首地址
	- 函数指针常用于回调函数，即将函数指针作为函数的参数的函数
	- 重定义

 ```C++
 int myAdd(int a, int b); //函数声明，底层逻辑就是函数指针
 int mySub(int a, int b);
 int fun(int a, int b, int (*myOp)(int, int))
 {
	 return myOp(a,b);
 }
 
 typedef int(*PFUN)(int, int); //函数指针类型重定义
 
 int main(void)
 {
	 printf("%d\n",myAdd(1,2));
	 int (*pFun)(int a, int b) =NULL; 
	 //函数指针，可以指向所有返回值为int且有2个int形参的函数
	 pFun = myAdd;
	 printf("%d\n",pFun(2,3));
	 
	 printf("%d\n", fun(10,2,myAdd));
	 printf("%d\n", fun(10,2,mySub));
	 PFUN pf;
	 pf = myAdd;
	 pf(1,2);
	 return 0;
 }
 
 int myAdd(int a, int b) //可以理解为函数定义后，就有了具体地址
 {
	 return a+b;
 }
  int mySub(int a, int b) //可以理解为函数定义后，就有了具体地址
 {
	 return a-b;
 }
 ```
