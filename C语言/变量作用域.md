- 局部变量
	在一个范围内有效的变量，一般定义在某一个块的内部
- 全局变量
	在全局范围（文件全局）内有效，一般定义在一个文件的开头
- 项目全局变量
	`extern int testVal`

# Static
- static变量
	使用域为局部，生存域在全局（文件全局）
	一般只用于局部区域，如果用在全局区域等同于全局变量
- static函数
	修饰函数在当前文件有效
	相对应的全局函数可以在整个项目中有效（导入头文件后才可以）

```C++
int main(void)
{
	for(int i=0; i<10; i++)
	{
		static int val = 0; //静态变量，修饰的是局部变量，该变量在块内使用，在块结束不会释放，生命周期等同于文件全局
		printf("%d\n", val++);
	}
	return 0;
}
```

```C++
#pragma once
extern int testVal=2;

int myAdd(int a, int b);    //使得myAdd为全局函数

```
Mytools.c
```C++
#include "Mytools.h"
#include <stdio.h>
static void testFun()       //静态函数只能在Mytools.c中使用
{
	printf("test test\n");
}

int myAdd(int a, int b)
{
	return a+b;
}

void fun()
{
	myAdd(12, 23);
}
```
sample.c
```C++
#include "MyTools.h"

int main(void)
{
	printf("%d\n", testVal);
	printf("%d\n", myAdd(1,2)); //来自于Mytools.c的可使用的全局函数
	return 0;
}
```
