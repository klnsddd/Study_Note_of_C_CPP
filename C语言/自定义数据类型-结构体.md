# 结构体
## 定义

- 结构类型定义
	`struct 结构体类型名 {成员列表};`
	**注意分号 ;**
- 结构变量定义
	- 三种定义方法
		1. 定义类型，通过类型给出变量 `struct 结构体类型名 变量名;`
		2. 定义类型的同时，给出变量 `struct 结构体类型名 {成员列表}ms;`
		3. 定义类型时，如果给出变量名，可以缺省类型名
			注意：无类型名，只能通过变量名去操作，无法通过类型去定义新的变量，只能采用第二种方法定义新结构体变量
	- 结构体变量的初始化赋值（在定义结构体变量的同时一次给成员列表中的数据赋初值）
	- 结构类型成员的访问 `变量名.成员`

```C++
struct MyPoint
{
	//成员列表
	int x;
	int y;
};
//定义了一个MyPoint类型，该类型是一个结构类型
struct MyStudent
{
	int id;
	char name[16];
	float score;
}ms = {2,"zhangsan",99.9f};  //定义类型的同时给出结构变量

struct      //缺省类型名
{
	int id;
	char sex;
}t = {1,'m'};

int main(void)
{
	struct MyPoint pos;
	struct MyPoint p = {10,20}; 
	p.x = 12;
	p.y = 23;
	if (strcmp(ms.name, "zhangsan")==0)
	{
	}
	return 0;
}
```

## 相关操作
- 类型重定义：typedef
	- 用新的类型名去代替原有的类型名
	- 用法
		1. 对非struct类型：typedef 原类型名 新类型名;
		2. typedef struct {...} Type;
			1. 在 C 里，`typedef` 常用于去掉声明时必须写的 `struct`；
			2. 在 C++ 里，结构体名本身就是类型名，不再需要 `typedef`。
- 在结构体成员列表中，可以使用数据或数组
- 在定义过程中，只是声明该结构类型有什么成员，这些成员没有具体内存，只有在通过类型给出变量的时候，成员才有具体的值
- 结构数组，是一个数组，数组里面的所有元素是同一样的结构类型
- 结构内存对齐
	结构的内存大小是以成员中最大内存的整数倍作为大小的
	如：struct中有顺序为`int(4)`,  `short(2)`, `char(1)`, struct的内存为8字节
		但若顺序为`short(2)`, `int(4)`, `char(1)`, struct的内存为12字节
		解释：short和char由于第二种顺序的原因无法结合放到相邻的4字节中，导致各要开出4个字节，导致了浪费
	**所以，在定义结构体成员时，要按内存从大到小（或从小到大）排列成员以节省内存**

```C
typedef int HP;

typedef struct MyPoint{
	int x,y;
} MP;

typedef struct Student {
    char name[20];
    int age;
    MP m;   //结构体嵌套
} Student;  // 最后的 Student 是“新类型名”

int main(void)
{
	HP hp = 10;  //HP是int类型的重定义的表现
	Student s1;   // 不需要再写 struct
	MP m[2] = {{0,1}, {1,0}}; //结构数组
	printf("%d\n", m[0].x);
	return 0;
}
```
