# 基本操作
- 文件指针
	`FILE* pf;`
- 文件相关操作通过库函数来完成
	- 打开与关闭文件
		`fopen(文件名, 使用文件的方式);`
		`fopen_s(&文件指针, 文件名, 使用文件的方式);`
		`fclose(文件指针);`
	- 打开模式（详见第三部分）
		`r` 只读    `w` 只写    `a` 追加    `rb` 二进制只读    `wb` 二进制只写    `ab`
		`w+`    `r+`    `a+`    
		当打开模式为`w`时
			若文件不存在，则自动创建该文件
			若文件存在，则打开文件并清除所有内容
		当打开模式为`r`时
			若文件不存在，返回空的文件指针

```C++
# include <stdio.h>
int main(void)
{
	FILE* pf = NULL;
	//pf = fopen("1.txt","w");
	fopen_s(&pf,"1.txt","w"); //参见多级指针
	fwrite("12345", 5, 1, pf);
	fclose(pf);
	return 0;
}
```

# 读写操作
读取要按照写入的顺序
- `fgetc`    从文件读取一个字符
- `fputc`    从文件写入一个字符
- `fgets`    从文件读取一个字符串
- `fputs`    从文件写入一个字符串
- `fscanf`/`fscaf_s`    格式化从文件读取数据
- `fprintf`  格式化向文件写入数据
推荐后两种
- `fread`      以二进制形式读取数据
	`fread(缓冲区, 读取字节数, 读取数据项个数, 文件指针);`
- `fwrite`    以二进制形式写入数据
	`fwrite(缓冲区, 写入字节数, 写入数据项个数, 文件指针);`
相关函数
- `fseek`    文件定位（使文件内部指针指向文件中的某个位置）
	`SEEK_SET`    文件起始位置 
	`SEEK_END`    文件末尾位置
	`SEEK_CUR`    文件当前位置
- `feof`    检测文件是否到了末尾，到末尾返回非0值，没到返回0值
## 写
```C++
int main(void)
{
	FILE* pf = NULL;
	fopen_s(&pf, "1.txt", "w");
	fputc('h', pf);
	fputs("ello",pf);
	int val = 100;
	double num = 3.14;
	fprintf(pf, "%d, %lf", val, num);
	int val1 = 200;
	fwrite(&val1, 4, 1, pf);
	fclose(pf);
	return 0;
}
```
## 读
```C++
int main(void)
{	
	FILE* pf = NULL;
	fopen_s(&pf, "1.txt", "r");
	char c = 0;
	c = fgetc(pf);
	char arr[16] = {0};
	fgets(arr, 5, pf);  //注意\0也算一字节
	int val = 0;
	float num = 0.0;
	fscanf_s(pf, "%d, %lf", &val, &num);
	int val1 = 0;
	fread(&val1, 4, 1, pf);
	fclose(pf);
	printf("%c, %s, %d, %1f, %d", c, arr, val, num, val1);
	return 0;
}
```

# 打开模式

`r` 只读
	若文件不存在，返回空的文件指针
`w` 只写
	若文件不存在，则自动创建该文件
	若文件存在，则打开文件并清除所有内容
`a` 追加
	若文件不存在，则自动创建该文件
	若文件存在，打开文件并定位到最后
`b` 二进制数据在`txt`文件中显示出来可能会有乱码，可以用`bin`文件
	`rb` 二进制只读    
	`wb` 二进制只写   
	`ab` 二进制追加
`+` 读写，既可读，又可写
	`r+`   文件必须存在          不清空原内容     从文件开头写
	`w+`   文件不存在则创建   清空原内容         从文件开头写
	`a+`   文件不存在则创建   不清空原内容      从文件末尾追加写
	
- **建议：文件操作时，尽量一次性读完，一次性写完，不要边读边写**

```C++
# include <string.h>
int main(void)
{		
	FILE* pf = NULL;
	fopen_s(&pf, "2.txt", "a");
	char* pArr = "12345";
	fwrite(pArr, strlen(pArr)+1, 1, pf);
	fclose(pf);
	
	FILE* pf1 = NULL;
	fopen_s(&pf1, "4.txt", "wb");
	int num = 999;
	fwrite(&num, 4, 1, pf1);
	char* pArr1 = "12345";
	fwrite(pArr1, strlen(pArr1)+1, 1, pf1);
	fclose(pf1);
	
	FILE* pf2 = NULL;
	fopen_s(&pf2, "2.txt", "r+");
	fwrite(pArr, 6, 1, pf2);
	fclose(pf2);
	return 0;
}
```
