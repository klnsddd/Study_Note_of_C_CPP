- 一些字符串操作
	- strlen 求字符串的长度
	- strcpy_s 字符串拷贝
	- fgets() 输入字符串
	- puts()  输出字符串
	- strcat_s() 字符串连接
	- strcmp字符串依次比较字符ASCII码，第一位不相等时结束比较并返回1或-1，相等了则比较下一位直到有ASCII码有不同或者全相同返回0。返回值为0表示两字符串相等，返回值为1表示参数1比参数2大，返回值为-1表示，参数1比参数2小
	- strstr() 用于在一个字符串（haystack）中搜索另一个字符串（needle）的第一次出现
- 怎么学习库函数
	1. 函数功能
	2. 参数的意思
	3. 返回值的意思

```C++
#include <stdio.h>
#include <string.h>
int main(void)
{
	char name[16] = "zhangsan";
	printf("%d\n",sizeof(name));
	printf("%d\n",strlen(name));
	printf("%s\n",name); //C语言格式化输出，%s输出字符串
	fgets(name); //字符串的输入
	puts(name); //字符串的输出
	
	char cArr[32];
	strcpy_s(cArr, 16, name); //参数：(目标字符串, 拷贝多少字节, 资源的字符串)
	strcat_s(cArr, 32, "12345");//参数：(目标字符串, 目标字符串的字节, 连接在目标字符串后的内容)
	if(strcmp(cArr, "zhangsan")==0)
		printf("==\n");
	else if(strcmp(cArr, "zhangsan")==1)
		printf("1>2\n");
	else if(strcmp(cArr, "zhangsan")==-1)
		printf("1<2\n");
	
	char cArr1[32] = "abcdabc";
	printf("%s\n", strstr(cArr1,"bcd"));
	// 输出 bcdabc
	
	return 0;
}
```
