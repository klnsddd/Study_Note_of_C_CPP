# 宏

宏：字符串替换，用于在源码编译之前，把源码中需要替换掉的内容替换掉
- 无参宏定义：`#define 宏名 替换的字符串`
- 带参宏定义：`#define 宏名(参数表) 替换的字符串`
- 有参需要注意运算符优先级可能会带来的问题
	`#define TEST(a,b) a*b   //可能有问题的写法`
	`#define TEST(a,b) (a)*(b)   //推荐的写法`
- 宏名习惯使用大写

```C++
#define PI 3.14   //不能写分号，分号也会被替换进源码，可能会导致错误
#define MYINT int  //尽量少用
#define TEST(a,b) a*b   //可能有问题的写法
#define TEST1(a,b) (a)*(b)   //推荐的写法
int main(void)
{
	double d = 2 * PI; //在编译之前，用“3.14”这个字符串替换到当前位置
	printf("%f\n",d);
	//PI = 1.11;    //错误代码，替换后PI变为3.14这个常量，不能把1.11赋值给常量
	MYINT a = 10;
	printf("%d\n", TEST(1+2,2+3));
	//输出实际为1+2*2+3=8，而不是(1+2)*(2+3)=15
	return 0;
}
```
# 文件包含

要用库函数，得有库函数的声明，在系统头文件中，所以要先包含系统的头文件(.h文件)
	注意：自定义函数的声明在 .h文件中，但具体的函数定义需要在 .c文件中，也需要导入 .h文件

- 尖括号
	在系统文件中去查找
- 双引号
	在当前项目中查找，如果找不到，再去系统文件中查找
- 允许嵌套包含
	- 在一个被包含文件中可以包含其他文件，如：文件A包含了文件B，文件B包含了文件C，那么文件A也可以使用文件C中的内容
	- 但注意： 不能重复包含，即在上述的例子中，A中不能包含C，否则会引起重定义的问题
	- `#pragma once`是VS中防止重复编译的语句，其他编辑器中可以使用条件编译

```C++
#include <stdio.h>
#include "MyTools.h"
#pragma once
```
# 条件编译

根据不同的条件编译不同的代码段
- `#if ... #else ... #endif`
	如果表达式为真，编译代码段1，为假，编译代码段2。endif结束
- `#ifdef ... #else ... #endif`
- `#ifndef ... #else ... # endif`
	如果没有定义宏，编译代码段1，否则编译代码段2。endif结束
- `#else` 不是必需，可有可无

```C++
#if 1
	int myadd(int a, int b)
#else
	int myadd(int a, int b, int c)
#endif
	return a+b;
```
