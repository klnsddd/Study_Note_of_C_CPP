# free与野指针

free指针指向的内存后，要将该指针指向NULL，否则指针指向的地址不变，就成了野指针，不知道free后的内存里是什么了


# 为什么在做数据结构时要定义指针而不是变量

## 为了让数据结构从堆区创建（而不是栈区）

这是核心原因之一：
### ✅ 在 main 中直接定义：

```C++
Arr arr;         // 在栈区
```

栈区变量的生命周期只在当前函数作用域内。

你不能这样返回它：
```C++
Arr* createArrWrong() 
{    
	Arr arr;     // 栈区     
	return &arr;  // ❌ 返回局部变量地址 → 野指针 
}
```
``
### ✅ 用 malloc 在堆区创建

```C++
Arr* arr = createArr();  // 堆区
```

堆区数据可以跨函数使用、跨文件使用、长期存活。
